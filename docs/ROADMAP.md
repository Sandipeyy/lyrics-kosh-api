# Lyrics Kosh roadmap

| Area | Current baseline | Remaining work |
|---|---|---|
| Worker foundation | Hono + TypeScript | CI and production config |
| LRCLIB | Adapter | Live contract tests and terms review |
| lrc.red | Adapter | Verify response formats and terms |
| Provider normalization | Unified record | Versioned schema validation |
| Caching | Workers Cache API | Provider-specific permission and cache policy |
| D1 catalog | Initial schema | Catalog ingestion and deduplication |
| Matching | Heuristic helper | Integrate, tune, test false positives |
| LRC | Basic parser | Metadata, offsets, word-level timing |
| TTML | Limited subset | Full TTML timing/namespace support |
| API security | API keys + starter quota | Native limiter, key rotation, abuse controls |
| Contributions | Pending queue | Rights evidence and audit workflow |
| Moderation | Approve/reject status | Takedowns, appeals, retention policy |
| SDKs | Starter examples | Contract tests and release pipeline |
| Monitoring | Basic cleanup/counts | Provider health, alerts, dashboards |
| Launch | Documentation | Security/legal/load/backup review |

This roadmap is a status document, not a claim that all areas are complete.
