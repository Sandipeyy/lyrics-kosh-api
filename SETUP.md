# Setup guide

## 1. Install dependencies

```bash
npm install
```

Use Node.js 18 or newer. Keep the lockfile generated by your own npm version committed to GitHub.

## 2. Create the D1 database

```bash
npx wrangler login
npx wrangler d1 create lyrics-kosh-db
```

Cloudflare prints a database UUID. Put that exact value into `wrangler.jsonc` under `database_id`. Do not invent a value.

## 3. Apply migrations

For local development:

```bash
npm run db:local
```

For the remote database after checking the target carefully:

```bash
npm run db:remote
```

## 4. Configure variables and secrets

Edit the provider User-Agent strings in `wrangler.jsonc` to include your real project URL and contact address.

Create the admin secret:

```bash
npx wrangler secret put ADMIN_SECRET
```

For local development, copy `.dev.vars.example` to `.dev.vars` and replace the placeholder. `.dev.vars` is ignored by Git.

## 5. Run locally

```bash
npm run dev
```

Open `http://localhost:8787/v1/health`.

## 6. Check code

```bash
npm run typecheck
npm test
```

## 7. Deploy

```bash
npm run deploy
```

After deployment, test `/v1/health`, `/v1/providers`, authenticated search, and admin authorization. Do not publish the API until provider permissions and security controls have been reviewed.

## Android note

These commands need a terminal environment that can run Node.js and Wrangler. If you are working only through the GitHub website on Android, you can upload/replace files there, but Cloudflare database creation, migrations, secrets, tests, and deployment are easier from a computer or a supported cloud development environment.
